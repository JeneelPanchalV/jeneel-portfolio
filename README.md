# Jeneel Panchal — Portfolio

Personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion. Features Lenis smooth scrolling, a glass-card project carousel, and scroll-driven typography animations.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```
